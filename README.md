# Minds Beneath Us 한글패치

Unity 게임 **Minds Beneath Us**(BearBone Studio)의 비공식 팬 한글패치 프로젝트입니다.
공식 한국어 지원은 없으며, 이 프로젝트는 게임사와 무관합니다.

**v0.2 alpha — 번역 100% 완료, 검수 전.** 대사·UI 텍스트 53,539줄 전부 번역되었지만,
아직 인게임 검수(오탈자·줄바꿈 깨짐·용어 일관성 확인 등)를 거치지 않은 알파 버전입니다.
어색한 부분은 [Issues](../../issues)로 제보해주세요.

## 다운로드 / 설치

최신 패치 파일: [MindsBeneathUsKorean.zip 다운로드](../../releases/latest/download/MindsBeneathUsKorean.zip)
(다른 이전 버전은 [Releases](../../releases) 페이지에서 확인 가능)
설치 방법은 [`install/INSTALL.md`](install/INSTALL.md) 를 참고하세요.

- `.dll`/`.exe` 등 실행 파일은 전혀 건드리지 않습니다. 데이터 파일(`.bundle`)만 교체합니다.
- 원본 파일은 설치 스크립트가 자동으로 백업하며, 제거 스크립트로 언제든 되돌릴 수 있습니다.
- 게임 안에서는 **설정 → 언어 → English** 를 선택해야 한글이 표시됩니다
  (영어 슬롯을 한글로 대체하는 방식이며, 일본어를 포함한 다른 언어는 손대지 않았습니다).

## 진행 상황

항목별 진행률은 [`progress.md`](progress.md) 에서 확인할 수 있습니다 (자동 생성 파일).

## 번역 원칙

- 원작은 번체중문이지만, 뉘앙스가 더 가깝다고 판단해 **일본어판을 번역 기준 원문**으로 삼았습니다.
- 인물/조직/장소 등 고유명사와 캐릭터별 말투는 [`translation/glossary.md`](translation/glossary.md) 에 정리되어 있습니다.

## 버전 히스토리

- **v0.2 alpha** (2026-08-12) — 남은 대사 챕터까지 번역해 전체 100% 달성. 화자 이름 매칭 버그와
  캐릭터명 표기 불일치 다수 수정, 대사 말투 일관성 검수.
- **v0.1 alpha** (2026-08-10) — 대사·UI 텍스트 번역 100% 완료 (검수 전 알파).
- **v0.0.1 alpha** (2026-08-09) — 최초 프리뷰 릴리즈. 번역 진행률 약 5.6%.

(자세한 내용은 [Releases](../../releases) 페이지 참고)

## 이 저장소에 없는 것

원본 게임 에셋, 디컴파일된 게임 코드, 게임 원문 그대로의 추출본은 저작권 문제로 이 저장소에
포함하지 않습니다. 릴리즈에는 로컬에서 빌드한 패치 파일(오버레이 데이터)만 첨부됩니다.
