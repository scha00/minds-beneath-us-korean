# 용어집 (Glossary)

번역 시 이 문서에 있는 고유명사/캐릭터가 나오면 **반드시 여기 등록된 표현을 그대로 쓸 것.**
없는 새 고유명사(인물/조직/장소/아이템 등)가 나오면 번역하면서 바로 이 파일에 새 항목으로 등록할 것.
(작업 방식은 `CLAUDE.md`의 "번역 시 용어집 사용 규칙" 참고)

데이터 출처: `translation/workbook/workbook.csv`(角色 시트, 章節 시트), `translation/dialogue/*.csv` 전수 스캔(대사 176명 화자 빈도 집계 + 상위 인물 샘플링).

## 세계관 메모 (대사에서 추론, 확정 아님 — 번역하면서 갱신할 것)

- 주인공은 `戴士傑`(ジェイ・ダイ, "제이"). "낯선 몸에 들어가 원래 몸 주인의 의식과 함께 지낸다"는 게임 소개와 맞물려, 대사 시점(視點)상 주인공이 남의 몸에 빙의한 상태로 보임.
- `万象`(완샹/완상, Wansiang) — 게임 내 최대 기업. `万象グループ`(완상 그룹), 산하에 `レッドボックス`(레드박스) 연구소 등이 있음.
- `工廠`(공장, "The Factory") — 주 무대가 되는 시설. 내부에 `操作組`(조작조/오퍼레이션팀), `選別組`(선별조, Workbook에서는 `篩選組`로도 표기됨 — 중국어 원문 표기 차이, 동일 조직), `建修組`(건설조) 등 부서가 있음.
- `フクロウ`(부엉이, "Owl") — 스이닝/린팅이 소속된 비밀조직/저항 세력으로 추정. 주인공을 영입하려 함.
- `ホワイトリザード`(화이트 리저드, "White Lizard") — 또 다른 세력/조직으로 언급됨. 정체 미확정.
- `ゴミ溜め`(쓰레기장, "The Dump") — 시민락(駱思敏)이 사는 지역. 공장이 배출한 유독 산업폐기물을 처리하는 곳.
- `MBU` — 게임 제목과 동일한 이니셜이 게임 내에서도 등장(校合者/무카이친 등의 대사). 정확한 뜻/설정 미확정 — 나중에 대사 더 보면서 확인 필요.
- `心の声`(속마음/내면의 목소리) — 화자 표기상 별도 캐릭터처럼 집계되지만, 자기 지칭이 "俺"(주인공과 동일)라 **주인공 본인의 내적 독백일 가능성이 높음** (원래 몸 주인의 목소리가 아닐 수 있음). 확정 아니므로 번역하면서 문맥 보고 재확인할 것.

## 챕터 구조 (章節 시트, 스토리 흐름 파악용)

```
0일차 - 병실
1일차 - 외출 / 공장-신입 / 공장-면담 후 / 공장-복도 소동 / 귀가
2일차 - 외출 / 공장-조작조 / 공장-선별조로 복귀 / 공장-매니저의 트러블 / 귀가(스이닝) / 귀가-류성과 23호
3일차 - 외출 / 공장-조사행동 / 공장-잠입 후 / 공장-연산 코어 / 귀가(우리 집) / 귀가-속마음 나누기
4일차 - 외출 / 공장-출근 / 공장-고요한 미래(선별) / 공장-고요한 미래(조작) / 공장-추적 / 폐기공장-악당 / 귀가-동요 / 귀가-결전 전야
5일차 - 외출 / 진실 / 최후의 선택
```
