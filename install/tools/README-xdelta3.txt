xdelta3.exe 안내
=================

이 폴더의 xdelta3.exe 는 오픈소스 프로그램 xdelta3 (버전 3.1.0, x86_64 Windows 빌드)이며 수정 없이
그대로 넣은 것입니다. 이 한글패치가 만든 프로그램이 아닙니다.

- 제작: Joshua MacDonald
- 라이선스: GNU General Public License v2 (전문: xdelta3-LICENSE-GPLv2.txt)
- 공식 배포처(바이너리와 소스코드): https://github.com/jmacd/xdelta-gpl/releases/tag/v3.1.0
    · 이 파일의 원본: xdelta3-3.1.0-x86_64.exe.zip
    · 소스코드: xdelta3-3.1.0.tar.gz
- 이 파일의 SHA-256: 6855c01cf4a1662ba421e6f95370cf9afa2b3ab6c148473c63efe60d634dfb9a
  (위 배포처의 zip 안에 든 xdelta3-3.1.0-x86_64.exe 와 동일한지 직접 비교해볼 수 있습니다.)

용도: install.ps1 이 사용자 PC의 원본 게임 파일에 "달라진 부분(diff)"을 적용할 때만 실행합니다.
한글패치의 다른 파일(install.ps1, patches 폴더 등)은 별도의 독립된 파일이며, xdelta3 와는 프로그램으로
분리되어 있습니다.
